# 📍 Live Location Tracker

A simple real-time location tracking web application that allows users to share and view live locations on a map. Built using modern web technologies for fast and accurate location updates.

---

## 🚀 Features

* 📡 Real-time location sharing
* 🗺️ Interactive map view
* 👥 Multiple user tracking support
* 🔗 Shareable location links
* 📱 Responsive design (mobile + desktop)
* ⚡ Lightweight and fast performance

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Maps API:** Leaflet.js / Google Maps API (if used)
* **Backend (optional):** Node.js, Express.js
* **WebSockets (optional):** Socket.io for real-time updates



## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/live-location.git
```

### 2. Navigate to project folder

```bash
cd live-location
```

### 3. Install dependencies (if backend exists)

```bash
npm install
```

### 4. Run the project

```bash
node server.js
```

### 5. Open in browser

```
http://localhost:3000
```

---

##  How It Works

1. User allows location access in browser
2. GPS coordinates are captured in real-time
3. Location is sent to server (if applicable)
4. Map updates instantly for all connected users

---

## 🔐 Permissions

This project requires:
